VALUTAX / PANDUAN PENGGUNAAN / VERSI 4.3.1

Panduan penggunaan dan penjelasan aplikasi ValutaX

Petunjuk menjalankan aplikasi, menghubungkan riwayat konversi ke Firebase, serta memahami rumus, grafik, dan struktur kode.

ValutaX menghitung konversi mata uang dan emas, menampilkan grafik perbandingan, serta menyimpan riwayat ke Cloud Firestore. Saat offline, data tersimpan tetap dapat digunakan dan riwayat baru menunggu sinkronisasi.

Mulai dari sini

  1. Ekstrak seluruh ZIP. index.html menampilkan aplikasi dalam bingkai HP, sedangkan website.html menampilkan website responsif. Semua file pendamping tetap berada dalam folder yang sama.
  2. Di Windows, jalankan JALANKAN_WINDOWS.bat untuk tampilan HP atau JALANKAN_WEBSITE_WINDOWS.bat untuk tampilan website. Di macOS/Linux, jalankan sh JALANKAN_MAC_LINUX.sh dengan Python 3. Biarkan jendela peluncur terbuka selama aplikasi digunakan.
  3. Pada aplikasi, buka Pengaturan Firebase untuk memeriksa konfigurasi dan menguji koneksi. Jika menggunakan proyek lain, ikuti petunjuk penyiapan Firebase.
  4. Gunakan tombol Konversi, Grafik, dan Riwayat untuk berpindah bagian aplikasi.

Kedua tampilan memakai fungsi konversi, konfigurasi Firebase, dan penyimpanan yang sama. Saat dibuka melalui alamat lokal yang sama pada browser yang sama, riwayat dan pilihan tema juga sama. Tautan di bagian bawah aplikasi dapat digunakan untuk berpindah tampilan.

1. Firebase dan fungsi database

Firebase adalah kumpulan layanan Google untuk aplikasi. Pada ValutaX, Cloud Firestore menyimpan riwayat hasil konversi. Firebase Authentication memberi identitas anonim kepada browser agar riwayat cloud hanya dapat diakses oleh identitas yang sesuai. Firebase Hosting dapat digunakan jika aplikasi ingin dibuka melalui link publik.

Ketiganya mempunyai tugas berbeda. Kurs mata uang berasal dari ExchangeRate-API, sedangkan harga emas berasal dari Gold API. Firebase tidak otomatis menyediakan kurs atau harga emas.

Data yang disimpan

Data yang disimpan adalah riwayat konversi. Setiap klik Simpan konversi membuat ID yang tetap digunakan saat pengiriman ulang. Aplikasi hanya menyimpan data konversi, tanpa kata sandi atau transaksi pembayaran.

users/{uid}/conversions/{idKonversi}

Path tersebut mengelompokkan riwayat berdasarkan UID Authentication. Dokumen profil users/{uid} tidak perlu dibuat; subcollection riwayat dapat ada tanpa dokumen profil.

Field FirestoreIsi dan tipe
amountAngka nominal asal, lebih dari 0 sampai 10¹².
from, toKode asal dan tujuan. Pada aplikasi ini, XAU digunakan untuk emas dalam gram.
result, rateHasil numerik sebelum pembulatan tampilan dan rasio konversinya.
sourceapi atau cache. Data contoh tidak dapat dikirim sebagai riwayat nyata.
savedAtTimestamp waktu penyimpanan menurut jam perangkat.
rateUpdatedAtTimestamp sumber yang digunakan; jika dua sumber terlibat, waktu yang lebih lama dipilih.

Status synced, UID, dan project ID juga disimpan lokal untuk mengelola antrean. Metadata tersebut digunakan untuk mengelola status sinkronisasi. Akses cloud dibatasi berdasarkan UID pada path riwayat.

2. Pemasangan untuk pemula

A. Jalankan berkas aplikasi

Ekstrak seluruh paket. Jalankan peluncur sesuai sistem operasi. Browser akan membuka alamat localhost:8000 yang tetap. Biarkan jendela server terbuka selama aplikasi digunakan.

Alternatif lewat terminal, dari folder aplikasi:
python mulai.py

Peluncur Windows menggunakan PowerShell yang tersedia pada Windows. Untuk macOS/Linux atau perintah python mulai.py, gunakan Python 3 dari python.org/downloads. HTTPS atau localhost diperlukan untuk fitur pembukaan ulang offline. Membuka index.html lewat file:// bukan skenario web yang didukung untuk integrasi ini.

B. Siapkan proyek Firebase

  1. Buka Firebase Console, lalu masuk menggunakan akun Google yang memiliki akses ke proyek.
  2. Buka proyek yang sudah ada atau pilih pembuatan proyek baru, misalnya bernama ValutaX. Pilih paket Spark untuk kebutuhan awal tanpa menambahkan akun billing. Paket ini tetap memiliki batas pemakaian layanan.
  3. Daftarkan aplikasi Web melalui ikon </>. Di Project settings → General → Your apps, salin objek firebaseConfig yang memuat apiKey dan projectId. Tidak perlu memasang SDK dari potongan contoh Console karena paket sudah mempunyai penghubung REST.
  4. Buat Cloud Firestore Standard edition dengan database (default), mulai dari Production mode. Pilih lokasi berdasarkan lokasi pengguna sebelum membuat database.
  5. Aktifkan Anonymous pada Authentication → Sign-in method. Identitas anonim digunakan aplikasi; ini berbeda dari akun Google pengelola.
  6. Di tab Rules Firestore, tempel seluruh isi firestore.rules dari paket dan tekan Publish. Aturan hanya memperbolehkan pengguna membaca dan menulis riwayat pada UID yang sesuai dengan format data yang valid.

C. Hubungkan melalui halaman pengaturan

  1. Buka Pengaturan Firebase pada aplikasi, atau halaman setup.html.
  2. Tempel objek firebaseConfig lalu tekan Simpan pengaturan. Halaman menerima format objek JSON maupun const firebaseConfig = { ... }.
  3. Tekan Uji koneksi Firebase. Pesan berhasil membuktikan akses baca Firestore, belum membuktikan penulisan hasil konversi.
  4. Kembali ke aplikasi. Tunggu kurs valid, hitung satu konversi, lalu tekan Simpan konversi. Pastikan status riwayat menjadi Tersimpan di Firebase dan dokumennya terlihat di Console.
Simpan pengaturan berlaku pada browser yang sama. Untuk perangkat lain atau hosting, tekan Unduh firebase-config.js dan gunakan file tersebut menggantikan file bernama sama sebelum menerbitkan aplikasi. Konfigurasi dalam file proyek mempunyai prioritas atas pengaturan browser.

Jangan mengganti konfigurasi dengan alamat email. Objek Web mengidentifikasi proyek; password dan private key tidak diperlukan di kode web. Parser pengaturan menolak file service account.

Halaman dibuka ulang offlineTersedia setelah kunjungan online pertama dan pesan siap offline muncul. Kunjungan pertama ke website tetap membutuhkan jaringan.

Badge Online/Offline pada header menunjukkan status jaringan perangkat. Label Firebase menunjukkan hasil pemeriksaan layanan secara terpisah. navigator.onLine tidak digunakan sebagai bukti bahwa server Firebase dapat diakses.

Permintaan mempunyai batas waktu delapan detik. Saat halaman aktif, pemeriksaan antrean dilakukan setiap 30 detik untuk kegagalan sementara atau data tertunda; pembacaan rutin saat tidak ada antrean dikurangi menjadi sekitar dua menit. Kesalahan konfigurasi/izin menunggu perbaikan dan tombol Sinkronkan. Tidak ada janji pengiriman ketika browser ditutup.

Data lokal memakai localStorage; sinkronisasi dikendalikan aplikasi, bukan persistence otomatis SDK Firestore. Web Locks mengoordinasikan signup/refresh token dan sinkronisasi pada tab-tab browser modern agar tidak membuat identitas bersamaan. Pada browser tanpa Web Locks, gunakan satu tab; ID dokumen tetap melindungi dari duplikasi dokumen.

4. Rumus konversi dan fungsi grafik

Konversi mata uang

Semua kurs disusun terhadap USD. Misalkan r_asal adalah jumlah unit mata uang asal per 1 USD, r_tujuan adalah jumlah unit tujuan per 1 USD, dan A adalah nominal asal.

rasio = r_tujuan / r_asal
hasil = A × rasio

Contoh ilustratif: r_USD = 1 dan r_IDR = 16.000. Maka 100 USD × (16.000 / 1) = 1.600.000 IDR. Angka tersebut merupakan contoh perhitungan dan tidak menunjukkan kurs terbaru.

Konversi emas dalam gram

Harga emas dari Gold API dinyatakan sebagai USD per troy ounce. Aplikasi mengubahnya ke basis gram. Satu troy ounce setara 31,1034768 gram.

USD per gram = harga USD per troy ounce / 31,1034768
r_XAU = gram per USD = 31,1034768 / harga USD per troy ounce
hasil = nominal × (r_tujuan / r_asal)

Contoh ilustratif: harga 3.110,34768 USD/troy ounce setara 100 USD/gram. Dengan demikian, 100 USD setara 1 gram emas. Nilai XAU dalam aplikasi ini berarti gram; harga spot indikatif dapat berbeda dari harga produk emas, pajak, biaya, atau spread jual/beli.

Kurs valuta dan harga emas mempunyai waktu pembaruan masing-masing. Jika konversi menggabungkan keduanya, waktu sumber yang lebih lama dicatat pada riwayat. Snapshot emas disimpan dan permintaan berikutnya diberi jeda minimal 30 detik sesuai petunjuk penyedia.

Apa fungsi diagram pada halaman?

Grafik batang membandingkan nilai 1 EUR, 1 GBP, 1 MYR, 1 SGD, dan 1 CNY dalam mata uang tujuan. Misalnya, jika tujuan IDR, semua batang mempunyai satuan IDR. Jika tujuan gram emas, semua batang mempunyai satuan gram.

nilaiBatang = r_tujuan / r_valuta
lebarBatangPersen = nilaiBatang / nilaiBatangTerbesar × 100

Mengganti tujuan atau menukar asal-tujuan memperbarui grafik. Mengganti nominal input tidak mengubah grafik karena pembandingnya selalu satu unit valuta. Keterangan pada halaman menyatakan hal ini. Tombol Grafik membantu pengguna langsung menuju diagram.

Grafik digambar dengan HTML/CSS lokal. Tidak memerlukan Chart.js, font, atau gambar dari CDN untuk tampil offline. Grafik menunjukkan perbandingan nilai valuta, bukan tren perubahan kurs dari waktu ke waktu.

6. Contoh penggunaan

Langkah berikut menunjukkan alur konversi, grafik, penyimpanan riwayat, dan sinkronisasi.

  1. Buka aplikasi saat online dan tunggu kurs tersedia. Masukkan nominal, pilih mata uang asal dan tujuan, lalu amati hasil konversi.
  2. Tekan Simpan konversi. Riwayat tersimpan di perangkat, lalu dikirim ke Firebase. Status Tersimpan di Firebase muncul setelah server mengonfirmasi penyimpanan.
  3. Tekan Grafik dan ubah mata uang tujuan. Nilai serta satuan setiap batang mengikuti tujuan yang dipilih.
  4. Tunggu pesan siap offline. Putuskan koneksi, ubah nominal, lalu simpan hasil konversi menggunakan kurs tersimpan. Riwayat baru berstatus menunggu sinkronisasi.
  5. Buka ulang halaman saat offline pada browser yang sama. Halaman, riwayat, dan grafik tersedia dari penyimpanan lokal.
  6. Sambungkan kembali jaringan. Antrean dikirim otomatis; tombol Sinkronkan juga dapat digunakan. Status riwayat berubah setelah mendapat konfirmasi Firebase.
  7. Gunakan Unduh riwayat untuk menyimpan salinan data dalam format JSON.

7. Hosting, pemulihan, dan rujukan

Menerbitkan bila ingin link website

Database menyimpan data, sedangkan hosting menyajikan aplikasi melalui alamat publik. Untuk menggunakan Firebase Hosting, siapkan konfigurasi Firebase, pasang Firebase CLI, lalu masuk menggunakan akun yang memiliki akses. Jalankan perintah berikut dari folder aplikasi dan ganti ID_PROYEK dengan ID pada pengaturan Firebase.

npm install -g firebase-tools
firebase login
firebase deploy --only firestore:rules,hosting --project ID_PROYEK

Konfigurasi hosting tersedia dalam firebase.json. Peluncur lokal dan berkas konfigurasi server tidak disajikan sebagai aset website.

Jika terjadi masalah

Pesan/kondisiTindakan
Belum diaturBuka Pengaturan Firebase. Tempel konfigurasi Web dari proyek yang benar.
Anonymous belum aktifAktifkan penyedia Anonymous pada Authentication.
Izin ditolakPeriksa rules yang dipublikasikan dan pembatasan API key untuk layanan yang dipakai.
Database tidak ditemukanPastikan Cloud Firestore (default) dibuat pada projectId yang sama.
Menunggu jaringanPertahankan halaman/riwayat. Sambungkan kembali, lalu tunggu atau tekan Sinkronkan.
Sesi rusak atau berubahJangan langsung menghapus data situs. Gunakan Unduh riwayat untuk backup, lalu periksa konfigurasi proyek dan sesi. Sesi anonim yang terhapus tidak dapat dipulihkan hanya dengan masuk ke Firebase Console.
Harga emas belum tersediaPeriksa jaringan/sumber harga atau gunakan cache yang valid. Aplikasi tidak mengganti harga dengan angka tetap yang dianggap aktual.

Riwayat cloud menggunakan identitas anonim per browser. Sinkronisasi riwayat antarperangkat memerlukan fitur login akun permanen. Menghapus data situs menghapus antrean lokal dan sesi anonim. Aplikasi dijalankan melalui browser. Pembuatan APK dengan Cordova memerlukan berkas platform, cordova.js, izin jaringan, dan proses build yang sesuai.
