Pengaturan · ValutaX

Hubungkan riwayat ke Firebase

Halaman ini digunakan untuk mengatur koneksi Firebase. Pengaturan cukup dilakukan sekali pada browser ini. Data yang disimpan adalah riwayat konversi.

1. Siapkan proyek Firebase

  1. Buka Firebase Console, lalu masuk menggunakan akun Google yang memiliki akses ke proyek.
  2. Gunakan proyek yang sudah ada atau buat proyek bernama ValutaX. Untuk kebutuhan awal, gunakan paket Spark tanpa mengaktifkan layanan berbayar.
  3. Daftarkan aplikasi Web (</>) pada pengaturan proyek. Salin objek firebaseConfig yang memuat apiKey dan projectId.
  4. Buat Cloud Firestore Standard edition, database (default), dengan mode awal Production. Pilih lokasi sesuai pengguna proyek sebelum dibuat.
  5. Aktifkan Anonymous di Authentication → Sign-in method. Layanan ini memberikan identitas anonim pada browser aplikasi untuk mengatur akses riwayat.
  6. Di Firestore → Rules, tempel seluruh isi file firestore.rules dalam paket ini dan tekan Publish.

Panduan lengkap, contoh data, diagram alur, dan penjelasan rumus tersedia di panduan ValutaX.

2. Tempel konfigurasi aplikasi Web

Bisa berupa objek { … } atau potongan const firebaseConfig = { … };. Konfigurasi tidak dieksekusi sebagai kode.

Membaca pengaturan…

Simpan pengaturan berlaku pada browser ini. Untuk menjalankan pada perangkat atau hosting lain, unduh firebase-config.js dan ganti file bernama sama pada paket sebelum diterbitkan. Bila file proyek sudah berisi konfigurasi, file tersebut menjadi sumber pengaturan utama.

3. Periksa akses database

Tombol ini memeriksa pembuatan/pemakaian sesi anonim dan pembacaan Firestore. Setelah berhasil, kembali ke aplikasi dan simpan satu konversi untuk memeriksa penulisan data.

Jika koneksi gagal

Pesan Anonymous belum aktif, izin ditolak, atau database belum ditemukan menunjukkan bagian proyek yang perlu diperiksa. Saat internet terputus, riwayat aplikasi tetap lokal dan akan dicoba lagi setelah online. Sesi anonim berlaku pada browser yang sama; riwayat lintas perangkat memerlukan fitur login akun permanen.

Jika sesi rusak, pertahankan data situs dan gunakan tombol Unduh riwayat di aplikasi untuk backup. Jangan menghapus data browser sebelum memahami konsekuensinya: sesi anonim yang terhapus tidak dapat dipulihkan hanya dengan masuk ke Firebase Console.
